TERM PROJECT
Dream Business Full-Stack Web Application
I. Project Overview
For your term project, you will conceptualize, design, develop, test, and present a full-stack web application for your dream business.

Imagine that you are planning to establish your own business. Your business may be a café, restaurant, clothing store, computer shop, hotel, tutorial center, repair shop, salon, fitness center, online store, photography service, events business, or another appropriate business concept.

The project will be developed progressively throughout the term. Each milestone will correspond to the concepts and technologies discussed in class.

Your final output must be a functional full-stack web application that integrates:

Front End → Back End → Database



II. Project Objectives
At the end of the project, students should be able to:

Plan and conceptualize a web-based business application.
Design an appropriate user interface and user experience.
Develop structured web pages using HTML.
Apply CSS to create an organized and responsive interface.
Implement client-side interactivity using JavaScript.
Develop server-side functionality using PHP or Node.js.
Design and implement a MySQL database.
Connect a web application to a database.
Implement CRUD operations.
Test and debug a full-stack web application.
Present and demonstrate a complete working system.

Required fields cannot be empty.
Email addresses must use an appropriate format.

Prices cannot be negative.

The application should display understandable error messages when invalid information is submitted.

XVI. General Project Policies
The project will be developed progressively throughout the term.
Students must demonstrate their progress during scheduled milestone checks.
Students should be able to explain the structure and functionality of their code.
All major features included in the final project must be demonstrated during the final presentation.
The selected technologies must satisfy the required front-end, back-end, and database components.
Additional libraries and frameworks may be used when approved by the instructor.
The complexity of the project should be appropriate for the course. A smaller application that works correctly is preferable to an overly complicated application with incomplete features.
Students are encouraged to be creative with their business concept, design, and features while ensuring that all technical requirements are satisfied.

# Oracle Red Labs

## Company

Oracle Red Labs (ORL) is a fictional offensive security consultancy. It presents security assessment services such as penetration testing and adversary-focused engagements for organizations seeking to understand and improve their security posture.

## Target Audience

The website is for organizations considering offensive security services, including company representatives who may evaluate services, submit an inquiry, or book an engagement. It also serves registered clients who need to track engagements and access reports, as well as prospective visitors researching the company and its security approach.

## Purpose of the Website

The website introduces Oracle Red Labs, explains its services and methodology, and provides information for the kinds of clients it serves. It supports lead generation through contact inquiries and an engagement booking flow. A client portal lets registered clients track engagement status and access reports, while an administrator area supports management of services, inquiries, engagements, and published resources.
